# D213. The Exasol driver has no flavors

Status: Decided.

Ken answered the step 9 questions of [DRIVER.md](../DRIVER.md) for Exasol (W44) on 2026-10-11. This is his answer to item 11.

The WebSocket API of Exasol has one product behind it. The protocol versions 3, 4 and 5 are versions of one API (D205). The driver does not tell flavors apart.
